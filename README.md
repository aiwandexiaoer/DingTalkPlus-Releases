# DingTalkPlus

钉钉效率增强模块（LSPosed）。

## 下载

### 最新版本

| 文件 | 说明 |
|------|------|
| `DingTalkPlus_v1.0.apk` | 主模块 |
| `DingTalkPlus-NotifPool.zip` | Magisk 模块（防撤回必需） |

从 [Releases](../../releases/latest) 页面下载。

### 版本信息

`version.json` 记录当前版本号和下载地址，模块的「检查更新」读取这个文件。

## 安装

### 1. 主模块

```bash
adb install -r DingTalkPlus_v1.0.apk
```

或直接传到手机点击安装。

安装后：
1. 打开 LSPosed 管理器
2. 启用「DingTalkPlus」
3. 作用域勾选「钉钉」（`com.alibaba.android.rimet`）
4. 强制停止钉钉并重新打开

### 2. Magisk 模块（防撤回必需）

**为什么需要**：钉钉进程被杀后，模块的 hook 全部失效。需要 root 从外部轮询通知栏，
把消息原文存下来，才能在对方撤回时恢复。

**前提**：设备已 root（Magisk / KernelSU / APatch）

**安装**：
1. 打开 Magisk / KernelSU 管理器
2. 模块 → 从本地安装
3. 选择 `DingTalkPlus-NotifPool.zip`
4. 重启手机

**验证**：
```bash
adb shell su -c 'cat /data/adb/dingtalkplus-notifpool.pid'
adb shell su -c 'tail -5 /data/adb/dingtalkplus-notifpool.log'
```

**关闭**：管理器里停用模块，采集进程 4 秒内自动退出。

## 功能

| 分类 | 功能 |
|------|------|
| **消息** | 消息防撤回（含进程被杀后补录）、协议层防撤回、撤回原文存档、已读回执拦截、阅后即焚留存、拦截播放与点击上报、禁止 DING 自动确认、右滑回复、自动已读、消息归档与检索 |
| **外观** | 个性装扮解锁、导航栏 tab 全解锁、快捷操作核心项解锁、「+」菜单项筛选、底栏 tab 紧凑居中 |
| **自动化** | 自动回复、关键词提醒 |
| **定位** | 模拟定位、轨迹模拟、地图选点、高精度定位 |
| **伪装** | WiFi / 蓝牙 / BLE / 基站模拟、设备指纹、传感器伪装 |
| **反检测** | 反 Root/Xposed、反调试、移除 VPN 检测、隐藏框架痕迹 |
| **其他** | 拍照打卡替换、平板模式、解除截图限制 |

## 关于开发方式

本项目的代码 **100% 由 AI 编写** —— 架构、Hook 实现、界面、构建脚本，全部如此。

写这段不是为了说明 AI 有多强，而是想指出一件事：当实现变得廉价之后，
真正稀缺的是判断力 —— 做什么、不做什么、边界划在哪里。
能跑的代码随时可以再生产一份，值不值得这么做却只有人能回答。

所以比起实现，本项目更希望被讨论的是想法本身：哪些功能真的有用、
哪些设计考虑不周、哪些地方已经越过了合理使用的界线。
